CORAL's Python API is organized into a few key modules. Most users interact with CORAL through the CLI or `task.yaml` configuration, but the Python API is useful for writing custom graders or extending CORAL.

## Modules

- [Configuration](/docs/api/config) — `CoralConfig` and related dataclasses
- [Types](/docs/api/types) — `Task`, `Score`, `ScoreBundle`, `Attempt`
- [Grader](/docs/api/grader) — `GraderInterface`, `BaseGrader`, `TaskGrader`
- [Hub](/docs/api/hub) — Attempts, notes, and skills CRUD
