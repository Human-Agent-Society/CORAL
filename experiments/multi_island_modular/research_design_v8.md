# Hard v8 certified-composition mechanism positive control

## Status and estimand

v8 replaces the superseded v7 topology matrix. It is an integration-level
positive control, not the confirmatory evidence for the blog's general
multi-island claim. It asks:

> At what fixed feedback budget does migration increase the number of
> certificate-backed modules in an artifact that an agent actually submits,
> relative to the same two islands with migration disabled?

The primary paired contrast is `multi_island - partition`. `global_8` is a
secondary control. The estimand is transfer under balanced distributed
expertise, not a universal claim about institutions or spontaneous division of
labor.

## Why this task can identify transfer

There are 32 modules and eight agents. Paired agent identities own the same
four disjoint module lanes in every topology. Round-robin island assignment
places four complementary lanes on each island. Smooth and Rugged discovery
remain modular, but an exact active evaluation now issues a private-seed-bound
certificate. A candidate receives assembly credit only for exact bits carrying
their valid certificate.

`partition` can assemble certificates discovered within one island but the
analyzer never unions its two islands. A migrant carries its worktree,
candidate, and certificates to the other island, where a later real submission
can combine both lineages. Thus migration has a measurable causal channel
without revealing untested inactive-module correctness.

This is an intentionally mechanism-positive control. A later free-allocation
variant must remove assigned lanes before making claims about endogenous
specialization.

Only the Smooth 384/512 one-seed bracket should be run as the first LLM smoke
test. Do not launch the 40,960-query Rugged matrix unless that smoke test first
shows certificate discovery, a real migration, and a later submitted reuse.
Even a successful eight-seed v8 threshold remains plumbing evidence; the
free-allocation held-out NK study and real tasks carry the behavioral claim.

## Landscapes and calibrated anchors

* Smooth uses 32 independent 32-bit Hamming modules. Worst-case coordinate
  reconstruction plus an exact provenance submission costs 34 evaluations per
  module and 1,088 for all modules.
* Rugged divides every module into four public 8-bit groups. Each private
  group table has one exact value at 1.0, the complement at 0.90, and the other
  254 values deterministically sampled below 0.85. Exhaustive group search
  costs at most 1,025 evaluations per module and 32,800 for all modules. The
  frozen calibration reports strict one-bit local-maxima counts.

The registered budget ladders are:

| task | budgets | fixed migration cadence |
| --- | --- | ---: |
| Smooth | 288 / 384 / 512 / 768 / 1,024 / 1,536 | 128 |
| Rugged | 8,192 / 10,240 / 12,288 / 16,384 / 24,576 / 32,768 / 40,960 | 2,048 |

The lowest cells bracket the first per-agent module certificate. The next
cells leave time for a post-discovery migration and a real consolidation
submission. Every budget is divisible across the fixed eight-agent roster.

## Outcomes and gates

Primary outcome: maximum valid certificate count in any candidate actually
submitted by an agent by the fixed budget. Secondary outcomes are maximum
ground-truth exact count in a submitted artifact, global discovered-module
count, assembly gap, certificate reuse across discovery islands, time to first
cross-island reuse, module coverage, duplicate-query rate, and per-agent quota
balance. Pooled discovery is diagnostic only.

A confirmatory cell requires the exact registered real budget, eight agents at
exactly one eighth of that budget, numeric feedback, correct private bundle,
at most one malformed candidate, at least eight active modules overall and
four per island, no migration events in controls, and a real migration event
when enabled. Above the calibrated first-certificate frontier, at least one
exact certificate is also required.

Synthetic cells allowlist only `api.appintheloop.com`, which the model runtime
requires. This is part of the integrity gate: source hosts such as GitHub stay
blocked, because a network-open participant could otherwise retrieve the
committed private-seed bundle and turn the black-box task into source lookup.

Eight private seeds are paired across conditions. The operational threshold is
the earliest budget at which the eight paired `multi_island - partition`
differences have a mean of at least two modules, a paired bootstrap 95% lower
bound above zero, and at least one chronology-backed cross-island certificate
reuse in every multi-island cell. All lower-budget cells remain reported.

## Required preflight and interpretation boundary

Before any LLM matrix, a deterministic policy simulator must show all of the
following: partition never receives a cross-island union, multi-island remains
equal to partition before a post-discovery migration, multi-island can exceed
partition only after a migrant's certificate is resubmitted, and global pooled
discovery is not used as the primary outcome. Grader tests must also show that
changing uncertified inactive bits cannot change feedback or assembly reward.

A positive result establishes sensitivity of CORAL's migration mechanism in a
certified compositional search. It does not establish semantic collaboration,
endogenous institutions, or superiority on arbitrary tasks. Those claims need
free allocation, communication-content ablations, additional real tasks, and
independent replication.
